# Test fixtures

Small, openly licensed audio, committed to the repository. Two groups, with different
origins and different rules.

## Conversion validation inputs

These are the exact files each model's Python-to-MLX conversion was checked against,
carried over from the conversion working trees. Tests run on them are therefore
directly comparable to those checks — which is why they are preferred over anything
equivalent-looking, and why `Scripts/fetch-fixtures.sh` neither generates nor
overwrites them.

| File | Rate | Validated model |
|---|---|---|
| `test.wav` | 16 kHz | FRCRN SE 16K |
| `test_48k.wav` | 48 kHz | MossFormer2 SE 48K (same content as `test.wav`) |
| `sr_input_16k.wav` | 16 kHz | MossFormer2 SR 48K |
| `speech_dialogue.wav` | 16 kHz | MossFormer2 SS, 2-speaker |
| `mix_8k.wav` | 8 kHz | MossFormer2 SS, 2-speaker / WHAMR |
| `mix3_8k.wav` | 8 kHz | MossFormer2 SS, 3-speaker |

## Fetched and derived

Regenerated byte-for-byte by `Scripts/fetch-fixtures.sh`.

| File | Rate | Source | Licence |
|---|---|---|---|
| `speech_long.wav` | 22.05 kHz | ClearerVoice-Studio `samples/path_to_input_wavs_sr/LJ001-0001.wav` (LJSpeech) | Apache-2.0 |
| `multi_speaker.wav` | 16 kHz stereo | ClearerVoice-Studio `samples/path_to_input_wavs_ss/speech_mixure1.wav` | Apache-2.0 |
| `music.wav` | 44.1 kHz stereo | *Distant Wonders*, "CC0 Instruments, Volume I", archive.org | CC0 1.0 |

[ClearerVoice-Studio](https://github.com/modelscope/ClearerVoice-Studio) is the upstream
of MossFormer2 SE/SS/SR and FRCRN and is Apache-2.0, the same licence as this project.

## Why the previous fixtures are gone

They were third-party recordings — an audiobook, commercial music, broadcast audio —
that we did not own and could not redistribute, along with derived outputs that
inherited the same status. They were removed from the entire git history, not just the
working tree, and nothing here descends from them.

## Coverage

8 kHz for the 3-speaker and WHAMR separation variants; 16 kHz for FRCRN, MossFormer2
SS and MossFormerGAN; 22.05 kHz as super-resolution input; 44.1 kHz stereo for Demucs;
48 kHz for MossFormer2 SE 48K.

Not yet covered: varied sound types for USS, which separates by AudioSet class and
needs material spanning animal, nature and things rather than speech and music alone.
